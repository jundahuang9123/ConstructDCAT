Construct-DCAT

A lightweight vocabulary for representation-independent semantic anchors on DCAT catalog records for heterogeneous construction datasets.

Scope

Construct-DCAT adds a small set of construction-oriented discovery anchors to dcat:Dataset records. It can be used in DCAT and DCAT-AP catalogs, but it is not a complete DCAT-AP profile and defines no SHACL constraints.

Representation independent: the catalog metadata is RDF, while the underlying distributions may be non-RDF IFC, AAS JSON, tabular, geospatial, sensor, or document data. RDF datasets are supported too.

The two dataset classes are initial examples, not an exhaustive taxonomy. Property objects may be IRIs from any suitable ontology, class hierarchy, AAS model, or controlled vocabulary; they are not restricted to a closed list.

Relationship to VoID

VoID can describe vocabularies, classes, properties, and partitions occurring within RDF datasets. Construct-DCAT instead exposes representation-independent semantic anchors on DCAT catalog records, including records for non-RDF datasets. RDF datasets may use both vocabularies together.
